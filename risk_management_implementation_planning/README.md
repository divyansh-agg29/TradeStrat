# Risk Modelling Planning

This directory contains the implementation plan for adding a fixed stop-loss risk system to TradeStrat, broken into smaller, more detailed phases.

## Documents

- [full_plan.md](full_plan.md) — the complete end-to-end implementation overview.
- [phase_1_foundation.md](phase_1_foundation.md) — data models, request plumbing, and module scaffolding.
- [phase_2_simulator_integration.md](phase_2_simulator_integration.md) — stop-loss execution inside the portfolio simulator.
- [phase_3_api_and_ui.md](phase_3_api_and_ui.md) — API payload support and frontend controls.
- [phase_4_testing_and_validation.md](phase_4_testing_and_validation.md) — test strategy, regression checks, and verification.
- [phase_5_future_extensions.md](phase_5_future_extensions.md) — how the design will support take-profit, trailing stops, and sizing later.
